Sanjai Murugan is an AI Engineer, AI Systems Developer, and Machine Learning Research Enthusiast focused on building intelligent, efficient, and deployable AI systems. His work primarily revolves around Retrieval-Augmented Generation (RAG), Large Language Models, Small Language Models, MLX-based fine-tuning, Computer Vision, and scalable AI infrastructure. He develops domain-specific chatbots, low-light computer vision systems, AI research pipelines, and lightweight language model architectures that combine practical engineering with advanced experimentation in model optimization and intelligent retrieval systems.

Sanjai has strong experience in Python-based AI development and works extensively with technologies such as LangChain, Vector Databases, LoRA Fine-Tuning, Apple MLX, OpenCV, React, Node.js, MongoDB, and API development. His technical interests include efficient AI systems, local LLM deployment, multi-agent AI architectures, mechanistic interpretability, and emotion-aware conversational AI.

One of his major projects is a domain-specific RAG chatbot repository called “rag-chatbot.” This project uses Retrieval-Augmented Generation to retrieve contextual information from custom knowledge bases and generate accurate responses using Large Language Models. The system includes semantic search, context-aware response generation, vector database retrieval, document ingestion pipelines, and LLM integration. The project demonstrates his expertise in LangChain, vector search systems, and intelligent AI retrieval architectures.

Another important project is “fine-tuning-SLM,” where Sanjai fine-tuned TinyOllama 1.1B using Apple MLX and LoRA-based parameter-efficient training techniques. The project focuses on generating emotionally aware, context-sensitive, and human-like responses while training only a very small percentage of the model parameters. The system is optimized for Apple Silicon hardware using MLX acceleration and explores lightweight Small Language Model optimization and efficient local AI experimentation. This project highlights his interest in efficient model adaptation, local inference systems, and scalable fine-tuning methodologies.

Sanjai also worked on an AI-powered low-light animal detection system in the repository “animal-detection.” This project uses thermally stimulated imagery generated from RGB input to improve animal detection performance in dark environments. The system integrates computer vision pipelines and OpenCV-based image processing techniques for enhanced visibility and wildlife detection research. The repository includes a published OpenCV-based release package for experimentation and deployment.

In addition to AI systems, Sanjai has experience building scalable web applications using the MERN stack architecture. His “mern-stack” repository focuses on REST APIs, frontend-backend integration, authentication systems, and database-driven applications using MongoDB, Express.js, React.js, and Node.js. This project contributed to his understanding of scalable backend systems and modern application development.
